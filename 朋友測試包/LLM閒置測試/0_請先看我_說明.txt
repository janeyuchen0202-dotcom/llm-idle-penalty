LLM 閒置測試：說明
==================================================

這是一個研究用的小測試：在你的電腦上跑一個小型語言模型，量「電腦閒置幾秒之後，
下一個請求會不會變慢」。全自動，不用安裝任何東西，也不會改你的設定。

收集的資料：每個請求的時間、GPU／CPU 的狀態（時脈、使用率、溫度）、硬體型號、
Windows 版本和電源設定。使用者名稱、電腦名稱和資料夾路徑都會自動遮掉。

--------------------------------------------------
步驟
--------------------------------------------------
1. 把下載的 zip「整個解壓縮」（在 zip 上按右鍵 → 全部解壓縮），
   之後的動作都在解壓縮出來的資料夾裡做。

2. 【建議】睡前跑：
   - 先存好檔案，關掉遊戲、影片、瀏覽器、動態桌布（例如 Wallpaper Engine）等其他程式。
     筆電請插上電源，最好不要闔上螢幕（有些筆電闔上會睡著，程式開始時會告訴你這台會不會）。
     桌機可以直接關掉螢幕。
   - 雙擊「1_睡前跑（GPU和CPU各10輪，跑完自動關機）.bat」，看完說明按 Enter，就可以去睡了。
   - 大約 2–4 小時後，結果會存到桌面，接著電腦在 2 分鐘後自動關機
     （關機時其他程式會被強制關閉，所以一定要先存檔）。
   - 隔天把桌面上的兩個「閒置測試結果_……zip」用 LINE 或 email 傳給我。

3. 想白天跑也可以（跑完不會關機）：
   - 「2_GPU閒置測試（現在跑，約1小時）.bat」優先，有空再跑「3_CPU閒置測試（現在跑，約1小時）.bat」。
   - 兩個各自獨立，順序不限，只跑其中一個也可以。跑完把桌面上的結果 zip 傳給我。

4. 結果都傳完之後，雙擊「4_清理測試資料夾（結果傳完再按）.bat」，輸入 Y。
   它只會刪掉這個測試資料夾；桌面上的結果 zip 會保留。

--------------------------------------------------
注意
--------------------------------------------------
- Windows 如果跳出「Windows 已保護您的電腦」：按「其他資訊」→「仍要執行」。
- 跑的時候不要點那個黑色視窗，也不要用電腦。電腦不會進入睡眠，螢幕會一直亮著，
  可以把亮度調低（桌機可以直接關掉螢幕的電源）。
- 防毒軟體擋下 llama-server.exe：那是開源的 llama.cpp（github.com/ggml-org/llama.cpp），
  可以按「允許」；不放心的話不跑也沒關係，跟我說一聲就好。
- 中途想停：直接關掉黑色視窗。半夜如果被 Windows 更新重開機也沒關係：
  下次雙擊任何一個測試時，程式會先把上次沒跑完的結果存到桌面。
- 畫面顯示「這台電腦找不到可以用的 GPU」：請把那個畫面截圖，連同桌面上的 GPU 結果 zip 一起傳給我，
  這台只跑 CPU 測試就好。
- 如果有幾輪被干擾（例如背景有程式在跑、筆電沒插電），程式會自動在最後多跑幾輪補上，
  所以時間可能比上面寫的久一點。
- 筆電不小心闔上睡著了也沒關係：打開後測試會自己繼續，睡著的那一輪會補跑。
  睡前跑如果中途睡著過，最後就不會自動關機。
